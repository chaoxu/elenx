03

The repair replaces fragile judgment with mechanical rules

Curators still summarize and route. They no longer mutate proof artifacts, confer truth, or decide whether proof bytes satisfy a boundary checklist.

Failure Rule now Effect
Repair text replaced a complete proof. Every distinct finding mints an immutable note. The original proof remains addressable forever.
Serve audited details it could not see. Serve recognizes only conclusion, parameters, and direction. Proof-content judgment moves to the exact-byte boundary.
Local checks demanded a complete campaign solution. Local verification judges one note's own claim. Definitions and lemmas can become usable premises.
Criteria mismatch refuted true mathematics. Criteria matching controls candidate acceptance only. A presentation omission rejects completion without erasing truth.
A guessed note ID could brick every resume. basedOn accepts visible non-report IDs before journaling. The model receives a retryable validation error.
Source inventory alone could mark a claim verified. Proof audit or reconstruction must establish truth. Source checks support a derivation but never replace one.
Summary drift retried identical failed proof bytes. Suppression compares exact candidate material across note IDs. Only changed proof bytes earn a new boundary attempt.
Prompt changes silently replayed old journals. The call surface has a stamp-keyed immutable golden. Changed prompts or schemas require an explicit new stamp.
Curator copied proof text into the statement channel. The provider-visible field is proposition-only, and a truth-establishing PASS carries an enforceable statement-form certificate. Proof remains in exact note text and cannot enter blind reconstruction through metadata.
A goal-equivalent ancestor could prove the target by restatement. Exact target premises are removed mechanically; the verifier ignores paraphrases, conjunctions, bundles, and leaked target conclusions. Reconstruction derives the campaign target rather than assuming it.
A standalone replacement cited expanded repair notes as provenance. basedOn now means logical premise only in both the explorer prompt and provider-visible tool schema. Copied or re-established mathematics creates no ancestor edge, so provenance cannot poison closure.
A boundary-rejected proof remained a verified ancestor. Non-criteria boundary doubt downgrades premise trust to conjecture; criteria-only mismatch stays candidate-scoped. Descendants cannot close over rejected proof bytes, and true but incomplete mathematics is not called false.
Empty-premise reconstruction was asked to rediscover an entire research reduction. A bundle certifier checks the high-level guide, allowed sources, direct verified premises, and transitive closure. A blind reconstructor receives only the certified direct interface, and a fresh comparator owns the verdict. Reconstruction can use the theorem's declared proof tower without seeing the candidate proof or every ancestor.
Curator authority

The curator proposes a short navigational summary and a proposition-only statement for every finding. It cannot replace, merge, drop, semantically deduplicate, verify, or refute the finding. Truth-establishing verifiers certify the proposal.

Verifier inputs

Proof audit sees the statement proposal and exact note text. Reconstruction sees the exact campaign target and admissible ancestor propositions but no proof text. Completion criteria are obligations, never premises. Criteria matching sees the exact stored candidate.

Failure semantics

Local mathematical failures can refute a note. A source or citation failure leaves it conjectural. Boundary verdicts audit the campaign target: a criteria-only failure rejects the candidate, while another boundary doubt revokes premise trust without calling a different stored proposition false.

Replay semantics

Structured requests, tool schemas, source requests, cache keys, labels, token estimates, and fold-authored defect text are pinned by one golden corpus named by the call-surface stamp.

06

The workflow passed. The V17 campaign did not finish.

Process evidence and mathematical resolution are different facts. V17 can now preserve and verify a proof tower, but its hard run has not yet exercised the repaired tower-aware reconstruction. A separate role-runner campaign later produced an accepted and independently audited proof of the theorem.

V17 CAMPAIGN · UNRESOLVED

Cyclic-couple proof tower

Two dependency-free candidates passed local and boundary proof audit, while blind reconstruction objected that it had no premises from which to rebuild the research reduction. The current repair calls for independently verified load-bearing lemmas and a goal note that cites only those direct premises.

WORKFLOW · IMPLEMENTED

Append-only re-triage

Serve may request one revised plan for a stuck conjecture. The new plan and verdicts append to the journal and supersede the old projection without mutating the note or its history.

RUNTIME · KNOWN RISK

Continuation headroom

One hard call continued with 128,713 input tokens while retaining a 128,000 output allowance. Another full continuation could exceed the 272,000-token context before Pi reduces the allowance.

SEMANTICS · MODEL-JUDGED

Paraphrased target premises

Exact target restatements are removed by code. A premise such as P and Q for target P remains visible, and the reconstruction verifier is instructed to ignore it. Absolute exclusion needs a formal proposition language or no ancestor premises, either of which changes the workflow.

BOTTOM LINE

V17's architecture was not disproved. The implementation let bookkeeping overrule mathematics. Immutable notes, certified statement proposals, noncircular reconstruction, scoped verification, candidate-trust downgrades, immediate boundary declaration, exact-byte suppression, and stamped replay now align the implementation with the original idea.
